# HOLDOUT

Top-down arena survival shooter in a single `index.html` (canvas + Web Audio, no external assets).
Open `index.html` in a browser to play.

- **WASD** move · **Mouse** aim · **Click/hold** fire · **P** pause · **M** mute
- Cover blocks bullets and acid: concrete walls and rocks are indestructible; crates, sandbags and red fuel drums break (drums explode and chain).
- Mud slows movement. Enemies path around cover; spitters only fire with a clear line of sight.
- Every 5th wave is a boss wave. Kills within 2s build a combo multiplier. High score is saved in localStorage.
